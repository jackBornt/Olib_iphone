安装到 iPhone

  1. 用 Safari 打开本站（需 https 或局域网地址）
  2. 点底部分享按钮
  3. 选择「添加到主屏幕」
  4. 确认后即可像 App 一样全屏打开

Windows 测试：运行 npm run windows 会打开独立应用窗口。
